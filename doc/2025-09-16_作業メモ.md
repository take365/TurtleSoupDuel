## 起動メモ（現状）
1. 仮想環境作成（初回のみ）: `py -3.11 -m venv .venv_win`
2. 仮想環境をアクティブ化: `.\.venv_win\Scripts\Activate.ps1`
3. 依存インストール: `pip install --upgrade pip && pip install -r requirements.txt`
4. FastAPI 起動: `python -m uvicorn app.main:app --port 8000`
5. フロントエンド起動: `cd web && npm install && npm run dev`

## 参考
- Cassandra 接続確認: `python scripts/test_cassandra_connection.py`
- Cassandra へのテーマ取り込み: `cd web && npm run db:import-themes`
